**Question:** Show the username of users who were tagged in a caption or photo before january 7th, 2010.

```sql
SELECT users.username, tags.created_at
FROM users
JOIN (
    SELECT user_id, created_at FROM caption_tags
    UNION ALL
    SELECT user_id, created_at FROM photo_tags
) AS tags ON tags.user_id = users.id
WHERE tags.created_at < '2010-01-07';
```

Now rewriting the above query in common table expressions.

```sql
WITH tags AS (
    SELECT user_id, created_at FROM caption_tags
    UNION ALL
    SELECT user_id, created_at FROM photo_tags
)
SELECT users.username, tags.created_at
FROM users
JOIN tags ON tags.user_id = users.id
WHERE tags.created_at < '2010-01-07';
```

This is Simple CTE(Common table expressions) which is good for understanding the query.


## Recursive CTE

```sql
WITH RECURSIVE countdown(val) AS (
    SELECT 3 AS val -- Initial, Non-recursive query
    UNION
    SELECT val - 1 FROM countdown WHERE val > 1 -- Recursive query
)
SELECT *
FROM countdown;

/*Output
val
===
3
2
1
*/
```

1. First we create Results table and working table.
2. Run the initial query and put both in results and working table.
3. Then run recursive table: `SELECT val - 1 FROM WORKING_TABLE WHERE val > 1`
4. And take the result and append inside `RESULTS_TABLE` and replace the whole `WORKING_TABLE` with the result.
5. Re-run the step 4 until no rows return
6. Return `RESULTS_TABLE` and available for outer query.

**Question:** Write a query that will tell suggested users to them. The logic for suggestion is to give suggested profiles are the profiles that are followed by followers of the user. user id is 1000 here.

**Answer:** We have to use recursive CTE here, we can first find all the followers of user id 1000 as initial query, then we will find all followers of those followers via recursive query.

```sql
WITH RECURSIVE suggestions(leader_id, follower_id, depth) AS (
        SELECT leader_id, follower_id, 1 AS depth
        FROM followers
        WHERE follower_id = 1000
    UNION
        SELECT followers.leader_id, followers.follower_id, depth + 1
        FROM followers
        JOIN suggestions ON suggestions.leader_id = followers.follower_id
        WHERE depth < 3
)
SELECT DISTINCT users.id, users.username
FROM suggestions
JOIN users ON users.id = suggestions.leader_id
WHERE depth > 1
LIMIT 30;
```
