# Polymorphic Association

A comment can be liked or a post can be liked.

Likes table:

| id | user_id | post_id | comment_id |
| --- | --- | --- | --- |
| 1 | 3 | 1 | NULL |
| 2 | 1 | NULL | 3 |

Add Check of
(
    COALESCE((post_id)::BOOLEAN::INTEGER, 0)
    +
    COALESCE((comment_id)::BOOLEAN::INTEGER, 0)
) = 1


```sql
SELECT COALESCE(NULL, 5) -- 5
SELECT COALESCE(10, 5) -- 10
SELECT COALESCE(NULL, NULL) -- NULL
```

Return first value if it is not null, otherwise second value
