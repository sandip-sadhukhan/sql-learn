# Create some sample data

```sql
CREATE TABLE accounts (
    id SERIAL PRIMARY KEY,
    name VARCHAR(20) NOT NULL,
    balance INTEGER NOT NULL
);

INSERT INTO accounts(name, balance)
VALUES
    ('Gia', 100),
    ('Alyson', 100);

SELECT * FROM accounts;
```


# How to open and close transaction

```sql
-- open a transaction
BEGIN;

-- Update some data
UPDATE accounts
SET balance = balance - 50
WHERE name = 'Alyson';

UPDATE accounts
SET balance = balance + 50
WHERE name = 'Gia';
-- Till now any changes made by this transaction will not visible by other users as this is saved in isolation for this connection pool user only.
-- If something crashes in between then the whole transaction will be rollback, and no data will be saved in DB.


-- Close the transaction and save the data for all
COMMIT;
```
