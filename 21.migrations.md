Instead of making db changes manually from PGAdmin etc, we can write a migration file in any programming language like Javascript or python, which will have code to apply database migration.

It is similar to django's `migration` folder.

Apply Migration
```bash
DATABASE_URL=postgres://sandip:password@localhost:5432/socialnetwork npm run migrate down
```

Revert Migration
```bash
DATABASE_URL=postgres://sandip:password@localhost:5432/socialnetwork npm run migrate down
```

We have a million records in posts table which has `lat` and `lng` coordinates values.
We want to use new field `loc` which is `Point` type which will store both data.

1. Add column `loc`
2. Deploy new version of API that will write values to both lat/lng and loc
3. Copy lat/lng to loc
4. Update code to only write to loc column
5. Drop columns lat/lng

If we update a record in a transaction, and from other connect try to update the same record, then it will wait until the first connection commit the transaction.
